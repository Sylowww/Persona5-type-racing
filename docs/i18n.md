# Internationalization

French (`fr`, default) and English (`en`). No user-facing string may be hardcoded in components.

## Files

- `src/i18n/locales.ts`: `locales`, `Locale`, `isLocale()`, `preferredLocale()` (cookie, then `Accept-Language`, then French) and `localizedPath()` (same page in another language).
- `src/proxy.ts`: redirects `/` to `preferredLocale()`.
- `src/components/layout/language-switcher.tsx`: header links to the current page in each language; a click saves the choice in the `locale` cookie.
- `src/i18n/dictionaries/en.ts`: source of truth; exports `Dictionary = typeof en`.
- `src/i18n/dictionaries/fr.ts`: typed as `Dictionary`, so a missing or extra key fails `npm run typecheck`.
- `src/i18n/dictionaries.ts`: `getDictionary(locale)` (server-only).
- `src/i18n/format.ts`: `formatMessage("Bet: {coins} coins", { coins: 150 })`.

## Adding text

1. Add the key to `en.ts`, grouped by area (`header`, `home.joinCode`, …).
2. Add the French translation to `fr.ts` (typecheck enforces it).
3. Pass the dictionary slice to the component as a prop.

## Conventions

- Dynamic values use `{placeholders}` + `formatMessage`; never concatenate translated fragments.
- Format numbers and percentages with `Intl.NumberFormat(locale)` (e.g. `2 410` in French, `2,410` in English).
- Keep casing natural in dictionaries; uppercase is applied with the `uppercase` CSS class.
- Brand name `TYPE//STRIKE` and player/rank data are not translated.
- French typography: space before `:` and `%` (`Mise : 150`, `98,4 %`).
